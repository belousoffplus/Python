# Poetry (версия 2.5.1)

> Вывод команды `poetry list`

## Использование

```text
команда [опции] [аргументы]
```

## Глобальные опции

| Опция | Описание |
| --- | --- |
| `-h`, `--help` | Показать справку по указанной команде. Если команда не задана — показать справку по команде `list`. |
| `-q`, `--quiet` | Не выводить никаких сообщений. |
| `-V`, `--version` | Показать версию приложения. |
| `--ansi` | Принудительно использовать ANSI-вывод. |
| `--no-ansi` | Отключить ANSI-вывод. |
| `-n`, `--no-interaction` | Не задавать никаких интерактивных вопросов. |
| `--no-plugins` | Отключить плагины. |
| `--no-cache` | Отключить использование кэшей Poetry (кэшированные метаданные пакетов и файлы дистрибутивов из настроенных источников) на время выполнения команды — Poetry будет вести себя так, будто кэш «холодный». Это не удаляет кэши: для удаления кэшированных данных используйте `poetry cache clear`. |
| `-P`, `--project=ПРОЕКТ` | Указать другой путь в качестве корня проекта. Все аргументы командной строки будут разрешаться относительно текущей рабочей директории. |
| `-C`, `--directory=ДИРЕКТОРИЯ` | Рабочая директория для команды Poetry (по умолчанию — текущая). Все аргументы командной строки будут разрешаться относительно указанной директории. |
| `-v` / `-vv` / `-vvv`, `--verbose` | Увеличить подробность вывода: 1 — обычный, 2 — более подробный, 3 — режим отладки. |

## Основные команды

| Команда | Описание |
| --- | --- |
| `about` | Показать информацию о Poetry. |
| `add` | Добавить новую зависимость в `pyproject.toml` и установить её. |
| `build` | Собрать пакет (по умолчанию — tar-архив и wheel-файл). |
| `check` | Проверить содержимое `pyproject.toml` и его согласованность с `poetry.lock`. |
| `config` | Управлять настройками конфигурации. |
| `docker` | Собрать Docker-образ. |
| `help` | Показать справку по команде. |
| `init` | Создать базовый файл `pyproject.toml` в текущей директории. |
| `install` | Установить зависимости проекта. |
| `list` | Показать список команд. |
| `lock` | Зафиксировать зависимости проекта. |
| `new` | Создать новый Python-проект по указанному пути. |
| `publish` | Опубликовать пакет в удалённом репозитории. |
| `remove` | Удалить пакет из зависимостей проекта. |
| `run` | Запустить команду в соответствующей среде. |
| `search` | Найти пакеты в удалённых репозиториях. |
| `show` | Показать информацию о пакетах. |
| `sync` | Обновить окружение проекта в соответствии с lock-файлом. |
| `update` | Обновить зависимости в соответствии с `pyproject.toml`. |
| `version` | Показать версию проекта или увеличить её, если указано допустимое правило bump. |

## Кэши (`cache`)

| Команда | Описание |
| --- | --- |
| `cache clear` | Очистить кэши Poetry. |
| `cache list` | Показать список кэшей Poetry. |

## Отладка (`debug`)

| Команда | Описание |
| --- | --- |
| `debug info` | Показать отладочную информацию. |
| `debug resolve` | Отладить разрешение зависимостей. |
| `debug tags` | Показать совместимые теги для текущей активной среды проекта. |

## Виртуальные окружения (`env`)

| Команда | Описание |
| --- | --- |
| `env activate` | Вывести команду для активации виртуального окружения. |
| `env info` | Показать информацию о текущей среде. |
| `env list` | Показать все виртуальные окружения, связанные с текущим проектом. |
| `env remove` | Удалить виртуальные окружения, связанные с проектом. |
| `env use` | Активировать или создать новое виртуальное окружение для текущего проекта. |

## Управление Python (`python`) — экспериментальные функции

| Команда | Описание |
| --- | --- |
| `python install` | Установить указанную версию Python из проекта Python Standalone Builds. |
| `python list` | Показать версии Python, доступные для этой среды. |
| `python remove` | Удалить указанную версию Python, если она управляется Poetry. |

## Собственное окружение Poetry (`self`)

| Команда | Описание |
| --- | --- |
| `self add` | Добавить дополнительные пакеты в среду выполнения Poetry. |
| `self install` | Установить зафиксированные пакеты (включая плагины), необходимые для этой установки Poetry. |
| `self lock` | Зафиксировать системные требования установки Poetry. |
| `self remove` | Удалить дополнительные пакеты из среды выполнения Poetry. |
| `self show` | Показать пакеты из среды выполнения Poetry. |
| `self show plugins` | Показать информацию об установленных плагинах. |
| `self sync` | Синхронизировать собственную среду Poetry в соответствии с зафиксированными пакетами (включая плагины). |
| `self update` | Обновить Poetry до последней версии. |

## Источники пакетов (`source`)

| Команда | Описание |
| --- | --- |
| `source add` | Добавить конфигурацию источника для проекта. |
| `source remove` | Удалить источник, настроенный для проекта. |
| `source show` | Показать информацию об источниках, настроенных для проекта. |
